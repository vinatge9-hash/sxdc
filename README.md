# Brew & Beans - Coffee Shop Website

This is a complete, production-ready set of static HTML pages for a coffee shop website created with Tailwind CSS (via CDN). It follows the provided design system and onboarding guidelines for a coffee-centric brand.

What’s included
- index.html: Home page with hero image, menu, about, testimonials, gallery, and CTA.
- about.html: Brand story, values, and team.
- contact.html: Contact form and location details.
- README.md: This documentation.

Design notes
- Theme: Coffee shop vibe with warm, earthy tones and Montserrat/Open Sans typography per category guidelines.
- Color palette (approximate Tailwind utilities): warm browns and creams; footer uses amber/cream-like tones to reflect a coffee environment.
- Typography: Font placeholders are used to indicate the category fonts. See 4.6.2 for mapping and how to replace with real imports if needed.

How to run
- These pages are standalone HTML files. You can open index.html in any modern browser or host on any static site server.
- They rely on Tailwind CSS via CDN for styling (no external CSS files are required).

Accessibility & quality
- All images include descriptive alt text.
- Semantic HTML5 elements used (header, nav, main, section, article, footer).
- Responsive, mobile-first layout with proper heading structure.

Notes
- If you want to deploy with a real hosting provider or adapt for a framework, this file set is ready to be migrated. For further enhancements, we can add a real assets pipeline, a small CMS, or switch to a static site generator.
